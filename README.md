# Contextual Memory Chatbot

This project implements a web-based chatbot with a persistent, interactive context memory system. 
Users can click on specific paragraphs returned by the LLM to save them into the active context (`context.json`). Future prompts will automatically inject these selected chunks into the LLM system prompt.

## Setup

1. Install `uv` if you haven't already.
2. Initialize the environment and install dependencies:
   ```bash
   uv add flask tiktoken requests
   ```
3. Run the application:
   ```bash
   uv run python app.py
   ```
4. Access the UI at [http://localhost:5005](http://localhost:5005)

## Configuration Options
In the UI, you can toggle between three modes:
- **Simulate:** Runs a mock LLM instantly (great for testing UI interaction).
- **Direct API Key:** Provide your Groq or OpenAI API key (defaults to model `llama-3.1-8b-instant`).
- **LLM Proxy:** Provide a local LLM proxy URL (e.g., `http://localhost:8000/v1/chat/completions`) generated by a tool like `llm-keypool` to utilize proxy load balancing and key rotation.
